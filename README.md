1.ความต้องการด้านฮาร์ดแวร์สำหรับผู้ใช้งาน (User Hardware Requirements)
------------------------------------------------------------------------------------------
อุปกรณ์ข้อกำหนดที่แนะนำ

- หน่วยประมวลผล (Processor) : Dual-Core ความเร็ว 1.5 GHz ขึ้นไป

- หน่วยความจำ (RAM) : 4 GB ขึ้นไป

- พื้นที่จัดเก็บข้อมูล (Storage) : มีพื้นที่ว่างอย่างน้อย 500 MB

- จอภาพ (Display) : ความละเอียด 1366 × 768 พิกเซลขึ้นไป

- อุปกรณ์รับข้อมูล (Input Devices) : แป้นพิมพ์และเมาส์

ข้อกำหนดเหล่านี้เป็นเพียงข้อแนะนำเบื้องต้น ยังไม่ได้ผ่านการทดสอบเพื่อยืนยันว่าเป็นข้อกำหนดขั้นต่ำของระบบ


2.ความต้องการด้านซอฟต์แวร์สำหรับผู้ใช้งาน (User Software Requirements)
------------------------------------------------------------------------------------------
- ระบบปฏิบัติการ Windows 10 หรือ Windows 11 แบบ 64 บิต

- ไฟล์โปรแกรมที่ผ่านการเผยแพร่เพื่อใช้งาน (.exe)

- สามารถเข้าถึงเซิร์ฟเวอร์ฐานข้อมูล MySQL หรือ MariaDB ได้

- ต้องมีการเชื่อมต่อเครือข่าย หากเซิร์ฟเวอร์ฐานข้อมูลอยู่บนคอมพิวเตอร์เครื่องอื่น

- ต้องติดตั้ง .NET Runtime หากวิธีการเผยแพร่โปรแกรมที่เลือกจำเป็นต้องใช้

ผู้ใช้งานไม่จำเป็นต้องติดตั้ง Visual Studio Code หรือ .NET SDK เพื่อเปิดใช้งานโปรแกรม หากโปรแกรมได้รับการเผยแพร่อย่างถูกต้องและมีส่วนประกอบที่จำเป็นครบถ้วนแล้ว
